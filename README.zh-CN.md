## 简介

Angular —— 现代 Web 开发者的平台。

Angular 是一个用于构建移动端和桌面端 Web 应用程序的开发平台,支持 TypeScript/JavaScript 等多种语言。官方站点:angular.dev。

## 文档

通过官方文档网站快速上手 Angular、学习核心概念并探索进阶主题:

- 入门指南(Getting Started)
- 架构(Architecture)
- 组件与模板(Components and Templates)
- 表单(Forms)
- API 参考

### 进阶主题

- Angular Elements:把 Angular 组件打包为自定义元素,嵌入任意页面
- 服务端渲染(Server Side Rendering):提升首屏速度与 SEO 表现
- Schematics:自定义代码生成与工程改造工具
- 惰性加载(Lazy Loading):按需加载组件,优化包体积
- 动画(Animations):内置动画系统,流畅的交互动效

## 开发环境搭建

### 前置条件

- 安装 [Node.js](https://nodejs.org/)(自带 npm 包管理器)

### 创建项目

全局安装 Angular CLI:

```
npm install -g @angular/cli
```

创建工作区:

```
ng new [PROJECT NAME]
```

运行应用:

```
cd [PROJECT NAME]
ng serve
```
