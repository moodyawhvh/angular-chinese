## 📖 项目简介

Angular 是谷歌开源的现代化 Web 应用开发平台,使用 TypeScript/JavaScript 等语言构建移动端与桌面端 Web 应用。它将依赖注入、组件化、响应式编程等工程化实践融为一体,开箱即用,被全球数百万开发者信赖。本项目为其 README 及核心文档的中文翻译介绍版本。

## ✨ 主要特性

- 跨平台:一套代码同时适配桌面浏览器、移动端与原生应用场景
- 现代化开发平台:基于 TypeScript 构建,类型安全,工程化程度高
- 速度优先:借助增量构建、服务端渲染(SSR)与混合渲染极致优化加载与运行性能
- 可扩展性强:从单人小项目到企业级大型应用都能从容应对
- 全能工具链:Angular CLI 一条命令完成创建、开发、测试与构建部署
- 组件化架构:组件与模板体系成熟,数据绑定直观高效
- 强大的表单与路由能力:响应式表单、惰性加载路由开箱即用
- 生态丰富:Angular Material 组件库、Angular Elements、Schematics、Animations 全线支持
- 官方文档完善:angular.dev 提供从入门到进阶的完整教程与 API 参考

## 🚀 快速开始

1. 安装 Node.js(自带 npm 包管理器)。

2. 全局安装 Angular CLI:

```
npm install -g @angular/cli
```

3. 创建工作区:

```
ng new [PROJECT NAME]
```

4. 运行应用:

```
cd [PROJECT NAME]
ng serve
```

5. 浏览器打开提示的本地地址即可看到应用运行;更多教程请访问 angular.dev。
